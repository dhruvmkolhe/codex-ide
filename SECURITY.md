# Security Policy

## Supported Versions

CodeX is currently in active pre-release development (`v0.1.0`). Security updates and patches are applied directly to the primary branch:

| Version / Branch | Supported |
| :--- | :--- |
| `0.1.x` (`main`) | ✅ Active development & security patches |
| `< 0.1.0` | ❌ Unsupported (Pre-release history) |

---

## Reporting a Vulnerability

**Please do NOT report security vulnerabilities via public GitHub issues.**

Instead, please send an email to **[codex.ide@proton.me](mailto:codex.ide@proton.me)** with the subject line: `SECURITY: [brief description]`.

### What to expect:
- **Acknowledgment:** You will receive a confirmation reply within **24 hours**.
- **Updates:** We will provide status updates every **72 hours** until the issue is resolved.
- **Resolution:** If the vulnerability is accepted, we will patch it and credit you in the release notes (unless you wish to remain anonymous). If it is declined, we will provide a detailed technical explanation as to why.

We appreciate your efforts to make this project safer! 🙏
